# Output directory

These files are retained evidence rather than scratch output.

- `audit.json`: source-pinned C1–C3 finite audit.
- `claim_verification.json`: fail-closed live-contract result and score.
- `test_results.json`: reproducibility test result.
- `evidence_bundle.json`: SHA-256 inventory of the evidence surface.
- `publication_gate.json`: normalized release decision and claim statuses.
- `PUBLICATION_GATE_PASSED.json`: backward-compatible gate filename.

The supplemental Proposition 3.20 certificate reports its deterministic result and hash on the command line and in its companion page under `pages/`.
